Dual-Use Edge AI Project 01 Active Benchmark

VisDrone on Jetson Orin Nano (INT8)

TensorRT Jetson Orin Nano ONNX / INT8

Problem

Small-object aerial detection from UAVs requires low latency (<30 ms) under strict SWaP (Size, Weight, and Power) limits without cloud offloading.

Data

VisDrone2019-DET benchmark: high-altitude, oblique-angle drone imagery with dense, small, and partially occluded targets.

Method

Post-training INT8 calibration (entropy & minmax) and TensorRT engine optimization, comparing FP32, FP16, and INT8 trade-offs.

Hardware

NVIDIA Jetson Orin Nano (8GB, 7W & 15W power modes) with active thermal monitoring and INA3221 power rail telemetry.

Geo AI Project 02 Interactive Demo

Bayesian Optimization for Sequential Drilling

Gaussian Processes BoTorch / GPyTorch Hugging Face Space

Problem

Exploratory drilling is expensive and irreversible. Static grid drilling wastes meters in low-information zones.

Data

Synthetic 2D/3D anisotropic ore-grade fields and historical borehole assay distributions with realistic spatial correlation.

Method

Gaussian Process surrogate modeling with Matérn kernels and Upper Confidence Bound (UCB) / Expected Improvement acquisition.

Hardware / Runtime

Lightweight CPU/edge-capable inference deployed as an interactive simulation on Hugging Face Spaces.

Data Foundation Project 03 Open Dataset

National Geofond Digitized Dataset

OCR / Structuring Parquet Hugging Face Datasets

Problem

Decades of valuable Bulgarian geological survey data remain locked in scanned PDFs, tables, and archival reports unusable by modern ML pipelines.

Data

Archival borehole logs, lithological descriptions, assay tables, and coordinate metadata from the National Geofond.

Method

Document layout parsing, domain-specific normalization, coordinate validation, and schema standardization into clean Parquet/JSONL splits.

Results

Foundational open dataset enabling reproducible Geo AI benchmarks and regional subsurface modeling.
